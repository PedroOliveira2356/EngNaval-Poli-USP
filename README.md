# Engenharia Naval — Poli USP

Trabalhos e códigos desenvolvidos durante a graduação em Engenharia Naval e Oceânica na Escola Politécnica da USP.

## Estrutura

| Pasta | Disciplina |
|-------|-----------|
| [`Cálculo/`](Cálculo/) | Cálculo I e II — visualização interativa de limites, derivadas e integrais |
| [`Controle/`](Controle/) | Sistemas de Controle — modelagem e projeto de controladores para VANT subaquático |
| [`Dinâmica de Sistemas II/`](Dinâmica%20de%20Sistemas%20II/) | Dinâmica de Sistemas II — análise espectral, RAOs e simulação |
| [`Hidrodinâmica/`](Hidrodinâmica/) | Hidrodinâmica I e II — propulsores, fluxo potencial, plataformas SPAR |
| [`Hidrostática e Estabilidade/`](Hidrostática%20e%20Estabilidade/) | Hidrostática e Estabilidade — método dos painéis e propriedades hidrostáticas |
| [`Mecânica de Estruturas II/`](Mecânica%20de%20Estruturas%20II/) | Mecânica de Estruturas II — MEF, Abaqus, otimização de seções transversais |
| [`Métodos Numéricos/`](Métodos%20Numéricos/) | Métodos Numéricos — decomposição LU, quadratura de Gauss, mínimos quadrados |
| [`Otimização/`](Otimização/) | Otimização — métodos clássicos, algoritmos genéticos, Gurobi (MIP) |
| [`Processos Estocásticos/`](Processos%20Estocásticos/) | Processos Estocásticos — ARIMA, cadeias de Markov, dados portuários |
| [`Proj. Sistemas Oceânicos/`](Proj.%20Sistemas%20Oceânicos/) | Projeto de Sistemas Oceânicos — otimização de plataforma semi-submersível |
| [`Sistemas Logísticos/`](Sistemas%20Logísticos/) | Sistemas Logísticos — roteamento de veículos (CVRP, VRPTW) |
